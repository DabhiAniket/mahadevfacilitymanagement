## When permission is granted

1. In `src/data/visuals.ts`, set `permissionStatus: "granted"`, `permissionGrantedBy`, `permissionDate`, and `credit` (for example `"Photo: ..."`, or `"Visualisation: ..."` since these are renders) exactly as the owner specifies.
2. Fill in "granted by" and "date" in the table above.
3. The credit then appears on the site in the image label automatically.
4. Remove the two lines for `/assets/source/` and `/public/visuals/` from `.gitignore` only if the files should be versioned.
